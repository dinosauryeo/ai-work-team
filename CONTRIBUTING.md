# Contributing

Contributions are welcome when they preserve AI Work Team's core separation of responsibilities.

## Principles

- Discussion Mode clarifies intent; it should not implement.
- Planning Mode produces executable handoffs; it should not quietly make missing product decisions.
- Strict Worker executes approved scope; it should not redesign the project.
- Contradictions should be escalated, not hidden.
- Handoffs should work across sessions without relying on invisible chat history.

## Changes

When proposing behavioural changes:

1. Explain which mode is affected.
2. Explain why the existing behaviour is insufficient.
3. Include an example before/after workflow where useful.
4. Update relevant documentation and `CHANGELOG.md`.
5. Avoid introducing project-specific private information or secrets.

## Versioning

Use semantic-versioning intent:

- patch: clarification or compatible corrections
- minor: compatible new modes/templates/capabilities
- major: changed mode boundaries or handoff guarantees
